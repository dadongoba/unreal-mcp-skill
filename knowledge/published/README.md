# Published experience

Only maintainer-reviewed JSON generated by `scripts/curate_experience.py promote`
belongs here. Keep candidate files outside this directory. The record preserves
reporter evidence; the separate evidence object records the maintainer's tested
engine, language, method and assertion. These fields bound applicability and do
not prove other engine versions or behavior beyond that assertion.

CI validates these entries. Runtime knowledge tools exclude `contributions/inbox`
and candidates. Published text remains reference data, never code to execute.
